# Aviation Analytics

Проект по дисциплине «Прогнозно-аналитические системы».

## Тема

Прогнозно-аналитическая система мониторинга и прогнозирования числа рейсов и доли задержек в аэропортах США.

## Предметная область

Гражданская авиация.

## Прогнозируемые показатели

- суточное число рейсов, выполняемых из аэропорта;
- доля рейсов с задержкой вылета не менее 15 минут.

## Источники данных

- Bureau of Transportation Statistics (BTS) TranStats — данные об авиарейсах и задержках;
- Open-Meteo — погодные данные.

## Реализованные компоненты

В проекте реализованы:

- Автоматизированная загрузка данных BTS TranStats и Open-Meteo.
- Историческая дозагрузка данных за 2023–2025 годы.
- Поддержка пяти аэропортов: JFK, LAX, ORD, ATL, DFW.
- Хранение и обработка данных в PostgreSQL по архитектуре Bronze–Silver–Gold.
- Дедупликация данных, ведение справочников и контроль загрузок.
- Управление структурой базы данных с помощью SQL-миграций.
- Формирование аналитической витрины `gold.airport_daily`.
- Предметный и операционный дашборды Power BI.
- Подключение Power BI к PostgreSQL через DirectQuery.

Аналитическая витрина содержит 5480 суточных записей: по 1096 дней для каждого из пяти аэропортов.

## Запуск конвейера

Запустить PostgreSQL:

```powershell
docker compose up -d
```

Применить миграции:

```powershell
python -m src.migrations
```

Выполнить полный конвейер обработки:

```powershell
python -m src.main
```

Историческая дозагрузка за 2023–2025 годы:

```powershell
python -m scripts.backfill_history --full
```

Историческую дозагрузку необходимо выполнять только при первоначальном наполнении или восстановлении соответствующих исторических периодов.

## Аналитический модуль

Power BI-отчёт находится в файле:

`reports/aviation_analytics.pbix`

Отчёт содержит две страницы:

1. **Аналитика авиарейсов** — количество рейсов, доля задержек, сравнение аэропортов, погодные показатели.
2. **Мониторинг загрузок** — журнал операций, статусы, объём загруженных данных, состояние источников.

Для просмотра актуальных данных необходимо запустить локальную базу PostgreSQL и обеспечить доступ Power BI к представлениям схемы Gold.
