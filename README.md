# Aviation Analytics

Проект по дисциплине «Прогнозно-аналитические системы».

## Тема

Прогнозно-аналитическая система мониторинга и прогнозирования числа рейсов и доли задержек в аэропортах США.

## Предметная область

Гражданская авиация.

## Прогнозируемые показатели

- суточное число рейсов, выполняемых из аэропорта;
- доля рейсов с задержкой вылета не менее 15 минут.

## Источники данных

- Bureau of Transportation Statistics (BTS) TranStats — данные об авиарейсах и задержках;
- Open-Meteo — погодные данные.
